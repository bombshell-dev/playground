# `@bomb.sh/playground`

## Development

This is in-place example and experimental repository. Requirements to run these examples are within the `devEngines` in `package.json`.

```sh
pnpm install
# then run
pnpm playground # returns an example selector
```

## Projects

[`@bomb.sh/dom`](packages/dom/README.md) is a headless interactive DOM. Its framework integrations and demos live in `examples/preact`, `examples/react`, `examples/solid`, `examples/lit`, `examples/svelte`, and `examples/crank`.
