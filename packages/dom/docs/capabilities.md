# Capability matrix

Statuses describe this implementation and its checked-in tests. “Implemented and tested” means the scope in that row, not complete conformance to an entire specification. The full DOM/HTML/Web Components WPT suites have not been run.

| Area                               | Status                    | Supported scope / remaining boundary                                                                                                                                                                                                                                        |
| ---------------------------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Packaging                          | Implemented and tested    | Strict TypeScript, ESM-only exports and declarations; independent documents; no process globals, browser or worker dependency.                                                                                                                                              |
| Tree and mutation                  | Implemented and tested    | Element, Text, Comment, Attr, Document, DocumentFragment; arbitrary element names; moves, prevalidation, siblings, ownership, connectivity, cloning/import/adoption, textContent, HTML/SVG/MathML namespaces. Live read-only array views protect collections.               |
| Typed element names                | Implemented and tested    | `Elements` declaration merging; input/textarea/template/slot return actual specialized classes. Application declarations must match registered classes.                                                                                                                     |
| Host invalidation                  | Implemented and tested    | Connected changes only; detach invalidates the old document; focus and selection changes observable; listeners/dispatch alone do not invalidate; host owns scheduling.                                                                                                      |

## Milestone record

1. The pinned DOM/event baseline established the initial tree and event regression coverage.
2. Independent host invalidation, MutationObserver, focus/Dispatch, and text controls followed.
3. Live Range/Selection tests cover both ordinary edits and detached-tree mutations.
4. Custom elements, inert templates, parsing, shadow roots, and slots have focused unit tests and custom-element browser differential cases.
5. Framework integrations and their acceptance tests are maintained separately from the core package.

Further work should expand this matrix only after adding meaningful tests and accurate declarations. No unsupported browser API is advertised through structural casts or global interface replacement.
