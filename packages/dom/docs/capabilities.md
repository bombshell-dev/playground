# Capability matrix

Statuses describe this implementation and its checked-in tests. “Implemented and tested” means the scope in that row, not complete conformance to an entire specification. The full DOM/HTML/Web Components WPT suites have not been run.

Live read-only array views protect collections.                   |

## Milestone record

1. The pinned DOM/event baseline established the initial tree and event regression coverage.
2. Independent host invalidation, MutationObserver, focus/Dispatch, and text controls followed.
3. Live Range/Selection tests cover both ordinary edits and detached-tree mutations.
4. Custom elements, inert templates, parsing, shadow roots, and slots have focused unit tests and custom-element browser differential cases.
5. Interactive HTML adds forms, choice/value controls, details/dialog, host editing, manual slots, declarative shadows and document-local terminal factories. Browser differential observations and explicit divergences are recorded in [interactive standards](interactive-standards.md).
6. Framework integrations and their acceptance tests are maintained separately from the core package.

Further work should expand this matrix only after adding meaningful tests and accurate declarations. No unsupported browser API is advertised through structural casts or global interface replacement.
